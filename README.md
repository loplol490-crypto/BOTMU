# 🇰🇬 Kyrgyzstan AI Guide Bot

Telegram bot that acts as an AI travel guide for Kyrgyzstan.

## 🚀 Features
- Travel recommendations in Bishkek
- Food suggestions
- Information about Issyk-Kul
- Friendly AI-style responses

## 🛠 Tech Stack
- Python
- python-telegram-bot
- Railway (deployment)

## 🤖 How it works
User sends a message → bot responds as a travel guide.

## 📸 Example
/start → shows introduction
"what to see in Bishkek" → gives places

## 📌 Status
MVP version (working prototype)
